# astrbot_plugin_group_wake

AstrBot 分群专属动态唤醒词插件。

支持按群维度动态配置免 `@` 唤醒词，跨重启基于 **SQLite** 永久持久化，同时具备**零 I/O 延迟内存读缓存**与**群聊/私聊隔离保护**。

---

## ✨ 核心特性

1. **分群严格隔离**：
   - 每个群拥有完全独立的专属唤醒词列表，A 群设置的唤醒词绝不会影响 B 群。
   - 严格守卫私聊通道，在私聊环境下自动拦截不生效，不破坏私聊原生交互逻辑。
2. **零 I/O 极致延迟**：
   - 读写分离架构：开机（`@filter.on_astrbot_loaded`）全量预热至内存哈希字典。
   - 每条进来的聊天消息在微秒级内直接完成 $\mathcal{O}(1)$ 匹配，绝不阻塞 asyncio 事件循环与数据库连接池。
3. **安全持久化**：
   - 增删操作通过 `asyncio.to_thread` 异步写回本地 SQLite 数据表（开启 WAL 模式），跨重启完全不丢失。
4. **贪婪前缀匹配**：
   - 自动按唤醒词长度由长到短降序匹配，防止短词切断长词（例如配置了「小助手」和「小助」时，能精准匹配「小助手」）。
5. **智能消息流转**：
   - 若用户仅发送了唤醒词本身，插件友好应答问候；
   - 若唤醒词后跟随了其它指令或对话文本，插件自动剥离唤醒词前缀，点亮后续所有普通指令与 AstrBot LLM 对话引擎。
6. **QQ 官方规范精准鉴权**：
   - 深度遵循 [QQ 机器人官方文档规范](https://bot.q.qq.com/wiki/develop/api-v2/autogen/event/c2c_message_create.html) 对 `author.member_role` 的定义（`admin`=管理员、`owner`=群主、`member`=普通成员）；
   - 同时全面兼容 OneBot/aiocqhttp 的 `sender.role` 以及 AstrBot 全局 `admins_id` 配置，多平台统一精准鉴权。

---

## ⚠️ 重要权限前提（QQ 官方机器人必看）

QQ 开放平台官方机器人默认进群后**仅能接收到 `@机器人` 的事件消息**。  
若要群内成员无需 `@` 直接通过「唤醒词」触发机器人，**必须由群主**在群设置中授权：

> 📱 **群主设置步骤**：  
> 打开手机 QQ ➔ 进入目标群聊 ➔ 点击右上角【群设置】 ➔ 点击【群机器人】 ➔ 选中本机器人 ➔ 开启**「接收所有消息」**（或允许接收群内全部消息）。  
>  
> ⚠️ **特别提醒**：如果未开启该权限，腾讯服务器底层**完全不会向机器人推送**群内普通聊天消息，机器人**只能接收到 @消息**，因此免 @ 唤醒词将无法被感知并触发！

## 📌 指令列表

插件输出全面采用 **Markdown Tips 卡片** 风格，且命令均支持 **`<qqbot-cmd-input>` 点击直接复制/填入聊天框**：

| 主指令 | 兼容别名 | 权限要求 | 说明 |
| :--- | :--- | :--- | :--- |
| `/帮助 唤醒词` | `/帮助唤醒词`、`/唤醒词 帮助`、`/唤醒词` | 所有群员 | 查看动态唤醒词插件的使用说明与指南 |
| `/设置本群唤醒词 <词>` | `/添加本群唤醒词` | 群主/管理员 | 为当前群添加专属免 @ 动态唤醒词 |
| `/删除本群唤醒词 <词>` | `/移除本群唤醒词` | 群主/管理员 | 从当前群移除指定的动态唤醒词 |
| `/查看本群唤醒词` | `/本群唤醒词` | 所有群员 | 查看当前群所有已配置并生效的唤醒词（支持快捷点击删除） |
| `/清空本群唤醒词` | 无 | 群主/管理员 | 一键清空当前群所有的唤醒词 |

> **提示**：配置成功后，群员在群内无需 `@` 机器人，直接发送 `唤醒词 + 内容` 即可。  
> 例如设置了唤醒词 `小管家`，发送 `小管家 帮助` 或 `小管家 今天天气怎么样` 均可直接唤醒！

## ❓ 常见问题：唤醒词为空时如何表现？

1. **群内未配置唤醒词 / 唤醒词列表为空**：
   - 此时群聊保持原生的纯净交互模式，任何普通消息都不会被误唤醒；
   - 只有群员明确 `@机器人` 或发送全局前缀（如 `/`）时，机器人才会响应。
2. **设置时参数为空（如输入 `/设置本群唤醒词` 未带内容）**：
   - 系统会自动校验并拦截空字符，提示用户输入具体唤醒词，防止因空前缀匹配导致“全群每句话都被当成唤醒词回复”的刷屏风险；
   - 若要清空本群唤醒词，可发送 `/清空本群唤醒词`。
3. **聊天时仅发送了唤醒词本身（剥离后内容为空，如只发了「小助手」）**：
   - 插件将自动触发友好问候应答（默认：“在呢！有什么可以帮您的？”），并通过 `stop_event` 拦截后续无效流程，不额外消耗 LLM token 与指令解析资源；
   - 可在 Web 控制台中配置是否开启此应答及自定义应答语。

## ⚙️ 配置说明

可在 AstrBot 管理面板的插件配置中可视化调整：

- **allow_member_manage** (`bool`，默认 `false`)：是否允许普通群员配置唤醒词。关闭时仅群管理与机器人管理员可管理。
- **max_wake_words_per_group** (`int`，默认 `10`)：限制每个群最多可配置的专属唤醒词数量。
- **enable_reply_on_wake_only** (`bool`，默认 `true`)：当群员只发送了唤醒词本身时，机器人是否进行友好应答。
- **reply_on_wake_only_text** (`str`，默认 `在呢！有什么可以帮您的？`)：单发唤醒词时的应答语。

## 📦 安装方法

进入 AstrBot 根目录下的插件目录克隆本仓库即可：

```bash
cd data/plugins
git clone https://github.com/lzyllll/astrbot_plugin_group_wake.git
```

克隆完成后重启 AstrBot 即可自动加载并生效。
